# AIDD 研究范围

[返回首页](../README.md)

本仓库以 [ADMET 与药代动力学](../topics/admet.md) 为主线，结合 [基础方法与基准](../topics/foundations.md) 建立阅读体系。[知识地图](knowledge-map.md)展示各方向的关系，后续按下表扩展专题。

| 方向 | 重点研究问题 | 当前状态 |
|---|---|---|
| ADMET 与人体药代动力学 | 吸收、分布、代谢、排泄、毒性及跨物种 PK | 已建立专题；数量以自动生成的总表为准 |
| 分子表示与性质预测 | 图、SMILES、3D 表示，预训练与迁移 | 已有基础方法入口及 ADMET 应用文献 |
| 蛋白质表示与结构 | 序列模型、结构预测及药物发现应用 | 后续扩展 |
| 相互作用、对接与虚拟筛选 | 结合姿态、亲和力、打分与筛选可靠性 | 后续扩展 |
| 分子生成与多参数优化 | 活性、可合成性及 ADMET 约束下的设计 | 后续扩展 |
| 反应与合成路线 | 反应预测、逆合成与实验可行性 | 后续扩展 |
| 数据、基准与实验验证 | 数据质量、盲测、分布变化与复现 | 已有 ADMET 相关记录，其他方向后续扩展 |

新增专题沿用统一的论文记录结构，围绕具体药物发现问题组织方法、数据和实验结果。

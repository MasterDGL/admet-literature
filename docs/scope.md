# AIDD 研究范围

[返回首页](../README.md)

本仓库围绕 AI 辅助药物发现整理论文。当前完成的首个专题是 [ADMET 与药代动力学](../topics/admet.md)。以下方向用于指导后续纳入，不代表已经完成全领域检索。

| 方向 | 重点研究问题 | 当前状态 |
|---|---|---|
| ADMET 与人体药代动力学 | 吸收、分布、代谢、排泄、毒性及跨物种 PK | 已有 19 篇分类记录 |
| 分子表示与性质预测 | 图、SMILES、3D 表示，预训练与迁移 | 先收录有 ADMET 实验的相关论文 |
| 蛋白质表示与结构 | 序列模型、结构预测及药物发现应用 | 后续扩展 |
| 相互作用、对接与虚拟筛选 | 结合姿态、亲和力、打分与筛选可靠性 | 后续扩展 |
| 分子生成与多参数优化 | 活性、可合成性及 ADMET 约束下的设计 | 后续扩展 |
| 反应与合成路线 | 反应预测、逆合成与实验可行性 | 后续扩展 |
| 数据、基准与实验验证 | 数据质量、盲测、分布变化与复现 | 已有 ADMET 相关记录，其他方向后续扩展 |

新增专题仍使用同一组核心字段，优先完善一条研究主线，再扩展论文数量。只涉及通用机器学习而没有明确药物发现关联的工作不作为核心条目。

## Experimental setup and analysis

This is a review, with performance drawn from cited studies. Table S1 records features and AUC/ACC by method. Table S3 includes ProTox-II, FP-ADMET, HelixADMET and ADMETlab 2.0, with website access dated 2022-06-15.

Table S1 scores reflect the endpoints and experimental settings of different original studies; model comparisons require those source papers. Database sizes, tool versions and access dates in Tables S2–S3 are retained as historical records.

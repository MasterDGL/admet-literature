# TDC

**Therapeutics Data Commons: Machine Learning Datasets and Tasks for Drug Discovery and Development**

[返回ADMET 与药代动力学总表](../../topics/admet.md) · [返回首页](../../README.md)

**一句话概括：** 把药物发现中的多类数据和任务整理成统一接口与基准，让不同预测方法能够按共同规则比较。

分类：数据与基准。主题：数据基准、评价协议。

| 数据集 | 跨药物发现和开发任务的数据集合；本文聚焦其中 ADMET Benchmark Group 的 22 任务。会议论文整体覆盖范围大于 ADMET。 |
| 方法 | 建立任务定义、数据接口、标准化基准和公开榜单。 |
| 结论 | 提供数据加载、任务划分与评测工具，支持在统一设置下比较药物发现模型。 |

## 实验设置与结果分析

ADMET Benchmark Group 使用任务专属指标和骨架划分，并提供多随机种子评测流程。

22 任务中的毒性部分包括 hERG、AMES、DILI 和 LD50。TDC 还提供其他药物发现数据，使用时按具体 benchmark group 选择任务。
